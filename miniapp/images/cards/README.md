# 塔罗牌面图片说明

## 获取方式

Rider-Waite-Smith 塔罗牌（1909年出版）已全球公版，可免费商用。

### 推荐来源（任选其一）：

1. **Flickr免费相册**（推荐）
   https://www.flickr.com/photos/laird_of_kiloran/albums/72157627745527329/
   → 78张高清JPG，右键保存

2. **Hyper.ai数据集**（免费）
   https://hyper.ai/datasets/33623
   → ZIP包下载，62.5MB，全部78张

3. **MagikCharms**（$6.99，最高清）
   https://magikcharms.com/shop/divination-tools-digital/78-rider-waite-tarot-cards-vector-png-jpg-svg-digital-download/
   → 300 DPI PNG，商用品质

### 文件命名规则

下载后按此规则命名放入本目录：

```
images/cards/
├── 01.jpg    ← 0. 愚者 The Fool
├── 02.jpg    ← 1. 魔术师 The Magician
├── 03.jpg    ← 2. 女祭司 The High Priestess
...（按编号顺序）
├── 22.jpg    ← 0. 权杖王牌 Ace of Wands
├── 23.jpg    ← 1. 权杖二 Two of Wands
...
├── 78.jpg    ← 星币国王 King of Pentacles
```

## 图片要求

- 格式：JPG 或 PNG
- 尺寸：建议 600x1000px 以上
- 单张不超过200KB（微信小程序限制）
- 如超过200KB，用 TinyPNG 压缩后再放入

## 临时方案

如果暂时没有图片，小程序会自动使用CSS卡牌组件（深紫+金色文字展示）。
图片就绪后替换即可，无需改任何代码。
