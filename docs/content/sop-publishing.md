# 内容发布 SOP

## 公众号发布流程
1. 在 markdown 中完成初稿
2. 粘贴到公众号后台富文本编辑器
3. 调整格式：段间距、加粗关键句、添加分隔线
4. 添加小程序入口卡片（文章底部）
5. 设置封面图（16:9）
6. 预览发送到手机检查
7. 定时发布或立即发布

## 发布时间建议
- 周一「星光周运」: 周一早 8:00
- 周三/四「牌面故事」: 晚 20:00
- 周六/日「树洞精选」: 晚 21:00
