# 小红书品牌视觉模板

## 配色
- 背景: #1A1A3E (深靛蓝)
- 标题/强调: #F4D48C (暖金)
- 正文: #F0EDE8 (暖白)
- 辅助文字: #B8A9E0 (薰衣草紫)

## 字体
- 标题: 粗体，浅金色，居中
- 正文: 常规，暖白色，左对齐
- CTA: 小号，薰衣草紫

## 版式 (4:3 竖版)
1. 封面图: 暗底+发光金色大字标题 + 一张卡牌图
2-N. 内容图: 段落式排版，每页一个核心观点
最后一张: CTA "搜索「星光映照」小程序，抽你的今日牌 ✦"

## 标签策略
- 固定标签: #塔罗 #每日一牌 #星光映照 #自我探索 #女生成长
- 话题标签: 根据内容灵活添加
