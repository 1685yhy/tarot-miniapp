# 小红书发布 SOP

## 发布前检查
- [ ] 标题够吸引人吗？（含数字/悬念/反差）
- [ ] 首图够亮眼吗？（暗色底+金色大字）
- [ ] 标签齐全吗？（5个固定标签+2-3个话题标签）
- [ ] CTA明确吗？（引导搜索小程序）
- [ ] 排版有呼吸感吗？（短段落，emoji分隔）

## 发布时间
- 最佳: 工作日晚 20:00-22:00，周末早 10:00-12:00

## 互动维护
- 发布后1小时内回复所有评论
- 评论就是二次内容："这个牌我也抽到过！你当时的感受是什么？"
