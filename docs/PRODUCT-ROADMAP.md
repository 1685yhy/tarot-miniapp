# 星光映照 · 产品战略与执行规划 v2.0

> 塔罗是镜子，不是预言——AI 陪伴式自我探索空间
> 目标用户：都市女性 22-35 ｜ 定位：每日仪式 × 深度懂你 × 情感沉淀
> 三份深度调研整合：心理机制（巴纳姆/投射/叙事疗法）、星座能力矩阵、竞品留存付费模型

---

## 一、产品愿景：用户为什么每天都来

**三层价值递进**：
1. **每天来**：晨间星座能量 + 每日一牌 + 晚间复盘（双时段仪式）
2. **觉得准**：本命星盘三要素 + 7 天日记感知（感知不引用）+ 巴纳姆文案结构
3. **离不开**：牌运曲线 + 新月许愿闭环 + 塔罗师养成（情感沉淀=数据飞轮）

**不做**（红线）：具体事件预测、健康诊断、诱导消费、恐吓话术——测测 315 案例为最大反例。

### C. 心理层（渗透所有解读——本次重点落地）
| 机制 | 落地方式 |
|---|---|
| **认领层**（先接住再引导） | prompt：开头引用用户问题/昵称，先镜像已知自我再给新框架 |
| **外化重构层** | 逆位/困境牌启用外化模板（高塔=腾地方/死神=转化/宝剑十=可以放下了） |
| **行动层**（一句话+一件小事） | 每条解读结尾：1 个反思问题 + 1 个 30 秒可做的小事 |
| **投射引导** | 抽牌后先问"哪张最先抓住你"，用户自我归因 |
| **7 天日记感知**（感知不引用） | 注入状态摘要调整语气，严禁引用原文 |
| **无输入状态注入** | 未提问时按用户近况解读"此刻人生阶段的意义" |
| **红线过滤层** | 10 条禁语 system prompt 强制（绝对化预言/时间承诺/恐吓/命运定性/健康/伪读取/诱导消费/羞辱） |
| **危机处理** | 自伤关键词→转介话术+热线；免责声明放解读头部 |

## 三、执行路线（做全做深，不留半成品）

### 阶段一：AI 解读引擎升级（1 周）——"准"的工程学落地
**交付物**：
1. `ai_engine.py` prompt 系统升级：
   - 认领层规则（个人化开头 + 混合型文案：温和+一句软刺）
   - 外化重构层（逆位/高塔/死神/宝剑十模板库 few-shot）
   - 行动层（反思问题池 + 30 秒小事模板，按主题选择）
   - 红线过滤层（system prompt 顶部禁语 + 输出后校验）
   - 危机检测（自伤词→转介 + 热线）
2. 7 天日记感知注入（已由心理触达子代理实现，验收合并）
3. 无输入状态注入（同上）
4. 测试：50 条解读输出过红线词表回归；空问题解读不引用日记原文

### 阶段二：星座一期（1-2 周）——"每天来"的引擎
**交付物**：
1. 每日星座能量 4 格：`/horoscope/daily?sign=` 接口（AI 生成）+ 每日一牌页"星座能量"模块（E3 设计：4 格能量条+一句话）
2. 星座×今日牌联动：prompt 双信号叠加（牌面符号 + 星座当日能量）
3. 新月许愿页：`pages/moon-wish/`（月相动画 + 10 个愿望 + 归档日记）
4. 满月复盘：AI 对照愿望+近两周日记输出温柔复盘
5. 2026 星历事件表 + 推送：接入 daily_push.py（事件日特制文案，晨间 8:00 星座能量+晚间 21:00 牌复盘）
6. 水逆模式：9.18-10.10 全站语气切换（解读开头水逆小贴士 + 推送文案）

### 阶段三：星座二期（1 月）——"准"感与付费
**交付物**：
1. 出生信息页（日期/时间/地点）+ 三要素计算（月亮预计算表 + 上升 API/pyswisseph）
2. 三要素插画卡（CogView 水彩风）
3. 星盘牌阵（上升/太阳/月亮三位）+ 深度报告 19.9-39.9 元
4. 星座配对轻量版（兼容度+关系解读）
5. 会员扩权：三要素卡/月相复盘/深度联动解读次数

### 阶段四：收尾工程（随各阶段）
- 78 张牌面 E3 水彩重绘（4 张样张已出，确认后批量）
- 牌运曲线 + 星座能量曲线双曲线
- 塔罗师养成（亲密度）
- 全站文案过禁用词表

## 四、质量定义（"不做嘎嘎"的标准）

每个功能交付必须满足：
1. **完整闭环**：入口 → 流程 → 结果 → 下一步引导，无断点
2. **E3 视觉一致**：奶油底/细金描边/衬线，真实插画资产（CogView），无 CSS 模拟
3. **动效齐全**：进入/交互/反馈三段动效，等待态有进度感
4. **状态全覆盖**：加载/空/错误/成功四态
5. **文案过审**：全部文案过微信禁用词表（预测/算命/转运/化解）
6. **实测闭环**：IDE 截图 + vision 审查 + 交互实测 + 测试全绿
