## 1. 项目概况

### 1.1 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Python FastAPI (异步) + Uvicorn |
| ORM | SQLAlchemy 2.0 (异步) + Alembic（已配置但无迁移脚本） |
| AI 引擎 | DeepSeek API（专业塔罗提示词，3次自动重试 + 退避） |

### 3.3 已知限制

1. **无生产级数据库迁移管理** — Alembic 已安装但未初始化迁移脚本，生产环境依赖 `create_all()` 创建表结构，存在 schema 变更风险
2. **测试覆盖严重不足** — 仅 1 个健康检查测试，核心 API（readings、orders、chat、diary、share）均无自动化测试
3. **无 CI/CD 流水线** — 部署依赖手动操作，无自动化测试、构建、部署流程
4. **无管理员运营后台** — 无法查看用户数据、订单统计、审核内容
5. **无卡牌真实图片** — 使用纯 CSS 视觉效果而非实际塔罗牌面图片
6. **无 WebSocket** — AI 解读和追问采用 REST 轮询模式，非实时流式
7. **无用户通知系统** — 无法推送每日运势、会员到期等通知
8. **微信审核风险** — 塔罗/占卜属于敏感类目，可能需额外资质文件

### 4.2 部署流程

```bash
# ==================== 后端部署 ====================

# 1. 克隆代码
git clone <repo-url> /opt/tarot-miniapp

# 2. 配置环境变量（关键！确保所有密钥已填入真实值）
cd /opt/tarot-miniapp/backend
cp .env .env.production
# 编辑 .env.production，填写 4.1 节中所有必填字段

# 3. 放置微信支付证书

# 从微信商户平台下载 apiclient_key.pem 放入 certs/

# 4. Docker 启动
cd /opt/tarot-miniapp
docker compose -f docker-compose.yml up -d --build

# 5. 验证运行
curl http://localhost:8000/health
# 期望输出: {"status":"ok"}

# ==================== 前端上传 ====================

# 6. 修改 api.js 中 release 域名（第21行）为真实域名
#    'https://your-domain.com' → 'https://你的域名.com'

# 7. 用微信开发者工具打开 miniapp/ 目录
# 8. 点击"上传"按钮，上传为体验版
# 9. 在微信公众平台提交代码审核
```

### 4.3 微信审核注意事项

1. **类目选择**: 建议选择"工具 > 信息查询"或"教育 > 教育信息服务"，避免被归入"文娱-占卜"类
2. **审核可能被拒的理由**:
   - 小程序涉及"占卜/算命"内容 → 弱化命理暗示，强调"心理疏导/文化娱乐"
   - 支付功能需确保有真实商品交付，审核时提供测试账号
3. **建议审核策略**:
   - 第一次提交：关闭会员付费功能（或设置免费测试账号），通过后版本更新再开启支付
   - 或先提交无付费功能的轻量版，后续通过版本更新上线支付
4. **iOS 虚拟支付注意**: 小程序内购买虚拟商品在 iOS 端可能受 Apple IAP 限制，建议 iOS 端隐藏会员入口
5. **隐私合规**: 首次打开需有隐私协议弹窗，说明用户数据使用范围
