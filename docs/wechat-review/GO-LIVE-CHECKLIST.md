# 星光映照 · 上线前平台配置清单

> 代码层面已全部完成并实测通过。以下 4 项需要你（账号管理员）在各平台操作，做完即可提交微信审核。
> 操作时间约 30-40 分钟。

---

## 1️⃣ 微信商户平台：轮换 APIv3 Key + 配置平台证书 ⚠️最高优先

**为什么必须做**：当前 APIv3 Key 是键盘序弱密钥（可被猜测，支付安全风险）；平台证书未配置会导致**真实支付回调验签失败，用户付款后权益无法到账**。

**入口**：https://pay.weixin.qq.com → 登录 → 账户中心 → API安全

### 步骤
1. **轮换 APIv3 Key**（32 位随机字符）
   - 账户中心 → API安全 → APIv3 密钥 → 设置/重置
   - 生成一个随机 32 字符密钥（建议用密码管理器生成，**不要自己手打**）
   - 记下来发给技术人员填入服务器 `.env` 的 `WECHAT_API_V3_KEY`
2. **下载平台证书**
   - 账户中心 → API安全 → 平台证书 → 下载证书（.pem 文件）
   - 同时记下**证书序列号**（下载页面会显示）
3. **把证书文件 + 序列号给技术人员**：
   - 证书内容（pem 全文）→ `.env` 的 `WECHAT_PLATFORM_CERT`
   - 序列号 → `.env` 的 `WECHAT_PLATFORM_CERT_SERIAL`

### 验证方式
技术人员配置后，测试支付一笔（可用 0.01 元测试订单），确认回调到账。

---

## 2️⃣ DeepSeek 平台：轮换 API Key

**为什么必须做**：当前 DeepSeek Key 曾写入 git 历史（视为泄露）。

**入口**：https://platform.deepseek.com → API Keys

### 步骤
1. 删除旧 Key（`sk-08496...`）
2. 新建一个 Key，复制发给技术人员填入 `.env` 的 `DEEPSEEK_API_KEY`
3. 改完后确认小程序里的 AI 解读/聊天正常（每句话都有 AI 回复）

---

## 3️⃣ 微信公众平台：申请推送模板 ID

**为什么必须做**：当前推送模板是占位符，订阅消息功能发不出去。这是「每日 21:00 晚间推送」留存功能的前提。

**入口**：https://mp.weixin.qq.com → 登录 → 功能 → 订阅消息

### 步骤
1. 功能 → 订阅消息 → 选用模板
2. 搜索并选用以下模板（关键词要匹配）：
   - **每日塔罗提醒**类模板：需要关键词「牌名」「日期」（用于"今晚之牌"推送）
   - 若搜不到完全匹配的，选最接近的占卜/提醒/日记类模板，记下模板 ID
3. 把模板 ID 发给技术人员填入 `.env` 的 `WX_TEMPLATE_DAILY_CARD`
4. 可选：会员到期提醒模板 → `WX_TEMPLATE_MEMBER_EXPIRE`；年度报告模板 → `WX_TEMPLATE_ANNUAL_REPORT`

### 验证方式
技术人员配置后，在小程序里点「每日推送提醒」订阅，21:00 观察是否收到推送。

---

## 4️⃣ 隐私政策联系方式

**为什么必须做**：微信审核要求隐私政策有真实联系方式，当前是占位文案。

### 步骤
1. 准备一个**客服微信**（个人号/企业微信）或 **客服邮箱**
2. 发给技术人员填入 `miniapp/utils/config.js`：
   - `CONTACT_WEIXIN: '你的微信号'` 或 `CONTACT_EMAIL: '你的邮箱'`
3. 用户协议/隐私政策的"联系我们"章节会自动显示
