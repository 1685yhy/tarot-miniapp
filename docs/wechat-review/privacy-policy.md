# 星光映照 · 隐私政策

**更新日期：2026年7月27日**

祁县天天开心商贸行(个体工商户)（以下简称"我们"）深知个人信息对您的重要性，我们将按照法律法规的规定，保护您的个人信息安全。

## 一、我们收集的信息

| 信息类型 | 用途 | 是否必须 |
|---------|------|---------|
| 微信昵称、头像 | 在小程序内展示您的身份 | 是（微信自动提供） |
| 塔罗解读记录 | 生成AI解读内容，提供解读历史回顾 | 是 |
| 塔罗日记内容 | 在应用内保存和展示您的日记 | 否 |
| 会员/支付信息 | 处理会员购买和支付 | 是（由微信支付处理） |
| 设备信息 | 优化小程序性能 | 否 |

## 二、我们如何使用信息

- **AI解读**：您的提问和选择的牌阵会发送到AI服务（DeepSeek）以生成解读内容。AI服务不会存储您的个人信息。
- **支付处理**：支付由微信支付处理，我们不会收集或存储您的信用卡/银行卡信息。
- **数据存储**：您的解读记录和日记内容存储在加密的服务器数据库中。

## 三、信息的存储与保护

- 所有数据传输使用 HTTPS/TLS 加密
- 服务器位于中国大陆境内
- 我们采取合理的技术措施保护您的数据安全

## 四、您的权利

- 您可以在"我的"页面查看和删除解读记录
- 您可以要求我们删除您的全部数据（联系客服）
- 您可以随时取消授权，停止使用本小程序

## 五、免责声明

- 本产品定位为"娱乐与自我探索工具"
- AI生成的解读内容仅供自我觉察参考，不构成心理咨询、医疗、法律或金融建议
- 我们不从事算命、占卜等迷信经营活动
