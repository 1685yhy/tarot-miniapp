# 微信审核测试账号

## 登录方式（无需注册，无需账号密码）

本小程序采用微信一键登录：审核人员用微信打开**体验版**（或开发版/正式版）即自动完成登录（wx.login 授权），无需填写任何账号密码，可直接体验全部流程。

## 可测试流程（非会员）

- 首页浏览 + 时段问候 + 每日一牌抽取
- 百科搜索 + 筛选（78张牌）
- 卡牌详情查看（正位/逆位释义）
- 免费解读（5次/天）完整流程：选牌阵 → 抽牌 → AI 解读
- AI 追问（3次/天）
- 日记创建、图片上传与浏览
- 签到打卡 + 任务中心
- 社区每日话题（匿名发帖）
- 年度报告页（会员专属，需开通会员后体验）
- 会员页浏览（定价与权益对比）

## 会员功能演示

如需体验会员功能（解读次数升级、AI追问不限、年度报告等），审核人员可在**会员页**输入以下优惠码开通试用：

- 优惠码: `REVIEW2026`
- 有效期: 开通后 7 天（足够完成审核；如需延期请联系管理员重置）
- 说明: 该优惠码仅限审核使用，已在后端部署（会员API内置，与正式付费渠道无关）

## 审核注意事项

- 所有 AI 解读内容均标注"仅供参考，仅供自我觉察"字样
- 免费次数用尽后页面会提示开通会员，不存在强制付费门槛
- 如需管理员协助测试特定场景，请通过开发者预留联系方式（见隐私政策/用户协议）联系
