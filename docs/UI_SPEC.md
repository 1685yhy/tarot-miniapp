## 1. 设计哲学

### 1.1 核心理念

| 维度 | 描述 |
|------|------|
| **神秘感** | 黑暗深邃的基底 + 星光点缀，营造仰望星空的沉浸体验 |
| **仪式感** | 金色作为神圣色彩，渐变光效模拟烛光/圣光，按钮流光效仿占卜仪式 |

> 深邃 · 神圣 · 星光 · 神秘 · 仪式 · 奢华 · 宁静 · 力量

## 7. 动画系统

### 7.1 持续时间

| Token | 值 | 用途 |
|-------|-----|------|
| `--duration-fast` | 0.2s | 轻交互反馈 |
| `--duration-normal` | 0.3s | 标准过渡 |
| `--duration-slow` | 0.5s | 页面切换 |
| `--duration-shimmer` | 2s | 流光循环 |

### 7.2 缓动函数

| Token | 值 | 特点 |
|-------|-----|------|
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 弹性收尾 |
| `--ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | 平滑加速减速 |

### 7.3 关键帧动画清单

| 动画名 | 属性变化 | 用途 |
|--------|---------|------|
| `twinkle` | opacity 0.2↔1, scale 0.8↔1.2 | 星尘粒子闪烁 |
| `glow-pulse` | box-shadow 8→24→48rpx | 金色光圈脉冲 |
| `shimmer` | background-position 左右扫描 | 按钮流光 |
| `fade-in-up` | opacity 0→1, translateY 20→0 | 文字渐入上升 |
| `fade-in` | opacity 0→1 | 元素淡入 |
| `card-flip` | perspective rotateY 0→180deg | 卡片翻转 |
| `mystic-spin` | rotate 0→360, scale 1→1.15→1 | 占卜加载转盘 |
| `breathe` | opacity 0.6↔1 | 文字呼吸 |
| `border-flow` | background-position 扫描 | 渐变边框流动 |
| `float` | translateY 0↔-10 | 轻量浮动 |
| `pulse-scale` | scale 1↔1.05, opacity 0.7↔1 | 脉冲缩放 |

### 7.4 动画延迟工具类

`.anim-delay-1` ~ `.anim-delay-5` 对应 0.1s ~ 0.5s 延迟，用于交错入场。

### 7.5 渐进式入场

`.anim-fade-in-up-1` ~ `.anim-fade-in-up-5` 实现多元素依次淡入，产生仪式感的逐步呈现效果。

## 8. 组件规范

### 8.1 按钮

| 变体 | 类名 | 特征 | 用途 |
|------|------|------|------|
| 主按钮 | `.btn-primary` | 金色渐变 + 按钮阴影 | 核心操作：开始占卜、提交 |
| 流光按钮 | `.btn-shimmer` | 金色渐变 + 动态流光动画 | 吸引注意力的核心调用 |
| 二级按钮 | `.btn-secondary` | 金色描边 + 透明背景 | 次要操作：分享、取消 |
| 幽灵按钮 | `.btn-ghost` | 透明 + 悬浮变色 | 不强调的操作 |
| 文字按钮 | `.btn-text` | 仅金色文字 | 最轻量交互 |
| 小按钮 | `.btn-small` | 缩小版 | 紧凑空间使用 |

**交互准则：**
- 点击态：`scale(0.97)` 微缩反馈
- 流光按钮仅在关键路径使用（如"开始占卜"）
- 同一页面最多一个流光按钮

### 8.2 卡片

| 变体 | 类名 | 特征 | 用途 |
|------|------|------|------|
| 基础卡片 | `.card` | 深色底 + 细边框 + 阴影 | 通用内容容器 |
| 毛玻璃卡片 | `.card-glass` | 半透明 + 模糊效果 | 浮层/高级信息展示 |
| 高级金属卡 | `.card-premium` | 光晕背景 + 金色发光边框 | 会员、推荐、占卜结果 |
| 渐变边框卡 | `.card-gradient-border` | 流动渐变边框 | 特殊/高级卡片 |
| 可点击卡 | `.card-clickable` | 点击缩放反馈 | 可交互卡片 |

### 8.3 表单输入

- 输入框容器 `.input-box` 带聚焦高亮（金色边框 + 微光）

- 输入域 `.input-field` 透明背景，自适应高度

### 8.4 标签/Badge

| 变体 | 类名 | 特征 |

| 状态 | 实现 | 说明 |

## 9. 页面布局规范

### 9.1 页面容器

- `.page`: 标准页面（左右 24rpx 内边距）
- `.page-full`: 全宽页面
- 所有页面顶部添加 `.orb-top`，底部添加 `.orb-bottom` 增强氛围

### 9.2 区块组织

```
.orb-top (固定背景光晕)
.star-field (可选星尘粒子)
┌─────────────────────────┐
│  .section-block           │
│  ├─ .section-title        │ ← 左侧金色竖线装饰
│  └─ 内容区块              │
│                           │
│  .card / .card-premium    │ ← 卡片内容
│                           │
│  .btn-primary / .shimmer  │ ← 操作按钮
│                           │
│  .action-bar              │ ← 次级操作链接
└─────────────────────────┘
.orb-bottom (固定背景光晕)
```

### 9.3 标题规范

- `.section-title`: 左对齐 + 金色竖线，用于有层次的内容区
- `.section-title-center`: 居中金色，用于仪式感强的区域
- 标题与内容间距: `--space-lg` (20rpx)

### 9.4 操作栏

`.action-bar` 使用 flex 居中对齐，链接之间间距 `--space-huge` (48rpx)。

## 10. 使用指南

### 10.1 快速开始

在页面的 WXSS 中导入公共样式：

```css
/* 在页面的 .wxss 中 */
/* 无需额外导入，app.wxss 已 @import common.wxss */

/* 推荐页面结构：*/
.container {
  min-height: 100vh;
  /* 加背景氛围 */
  background: var(--color-bg);
  background-image: var(--gradient-bg-radial), var(--gradient-bg-radial-gold);
}
```

### 10.2 变量引用规范

- **颜色**：永远使用 CSS 变量，不硬编码色值
- **间距**：使用 `var(--space-*)` 而非魔法数字
- **圆角**：使用 `var(--radius-*)`
- **字体**：使用 `var(--fs-*)` 和 `var(--fw-*)`

### 10.3 动画使用原则

- 页面首次加载：使用 `.anim-fade-in-up-1~5` 让内容逐一出现
- 按钮：主按钮使用流光，次要按钮使用 `transition`
- 卡片：点击使用 `scale(0.97)` 反馈
- 加载态：占卜过程使用 `mystic-spin` + `breathe` 增强仪式感
- 不要过度动画 — 每个页面 2-3 个动画焦点元素即可

### 10.4 色彩使用原则

| 元素 | 颜色 | 说明 |
|------|------|------|
| 背景 | `var(--color-bg)` | 深空底色 |
| 卡片 | `var(--color-bg-card)` | 深色表面 |
| 主要标题 | `var(--color-gold)` | 神圣金色 |
| 正文 | `var(--color-text-primary)` | 明亮白色 |
| 辅助文字 | `var(--color-text-secondary)` | 柔和灰紫 |
| 次要信息 | `var(--color-text-dim)` | 低调灰 |
| 强调/行动 | `var(--color-gold)` | 金色贯穿 |
| 错误 | `var(--color-danger)` | 红色 |
| 成功 | `var(--color-positive)` | 绿色 |

### 10.5 高级氛围增强技巧

1. **顶部 + 底部光晕**：每个标准页面都加上 `.orb-top` 和 `.orb-bottom`
2. **星尘粒子**：首页/占卜页可添加 `.star-field` 带 8-10 个 `.star-particle`
3. **渐变边框**：卡片设置 `.card-gradient-border` 提升高级感
4. **交错入场**：3-5 个元素使用 `.anim-fade-in-up-1~5` 产生依次呈现的仪式感
5. **金色分割线**：`.divider-gold` 比普通分割线更细腻
