# 星光映照 · 迭代设计规划（全量规划 · 分期实施）

日期：2026-08-10
状态：用户已确认（两段设计均通过）
依据：目标用户高频功能调研（2026-08-10，含 15 项高频功能榜 + 竞品/留存数据）

## 一、设计总纲：三合一差异化

用户选择"效果最好"方案（不考虑成本），专业判断：**中叙事星阶成长为主 + 星灵引导角色**（重叙事的星灵吸收、复杂故事线砍掉——塔罗用户是"每日 1 次轻量仪式"型，47% 用户每日使用；Co-Star/测测/月见无靠故事线成功者；星阶成长直接挂钩留存数据）。

- **壳**：星光叙事体系（记忆点，市面唯一）
- **核**：三源加权"准"（真实天象+塔罗牌面+日记状态，可解释可验证）
- **气**：治愈系仪式感（E3 奶油疗愈，情绪被看见）

## 二、世界观与命名体系

| 现功能 | 星光化命名 | 用户感知 |
|---|---|---|
| 每日能量 | 今日星光（每天一颗专属星） | 每天有"今天属于我的星" |
| 每日一牌 | 星光指引 | — |
| 签到 | 收集星尘 | 签到=收集星光能量 |
| 成长体系 | 星阶：微光(0)→星光(7)→星辉(30)→星冠(100) | 越用越亮的成长感 |
| 分享海报 | 星光名片 | 我的星象身份卡 |
| 晨间推送 | 星光晨讯 | 每天 7:37 星光点亮 |
| AI 引导 | 星灵·小星（轻量引导角色） | 有人陪伴的温柔感 |
| 幸运色/数字/宜忌 | 星光色 / 星光数 / 星象宜忌 | 有出处、可分享 |

## 三、P0 四补丁详设（第 1 期，2 周）

### P0-1 星光晨讯（订阅消息）
- 触发：抽牌/占卜/许愿完成后弹一次订阅引导（「订阅后，明早收到你的今日星光」）；微信一次性订阅=授权 1 次 1 条额度
- 额度管理：后端攒额度，次日 7:37 按序发送（基于现有 daily_push 定时任务改造）
- 内容：今日星光一句话 + 能量值 + 星光色 + 星光数 + 星象宜忌（1 条容量内）
- 防疲劳：每天 1 条封顶（晨讯/睡前星语共享额度）、可一键取消
- 微信侧待办（用户）：公众平台申请订阅消息模板 2 个——①每日星光（如模板 ID 含"运势/提醒"类目）②节点活动

### P0-2 星光名片（分享海报升级）
- 构成：今日星光卡牌面 + 今日关键词 + 星阶徽章 + 星光数 + 小程序码
- 版式：E3 统一身份卡样式，每张名片独有星光色边框；海报底部「仅供娱乐 · 星光映照」小字
- 实施要点：小程序码不能用 tabbar 页生成 → 需独立"名片落地页"（/pages/card-landing/ 接收 scene 参数展示名片+引导下载/关注）；海报文案过内容安全检测

### P0-3 星尘签到（每日免费 + 收集体系）
- 每日免费：每天 1 次免费深度解读（沿用 free_deep_readings 机制），话术"星光馈赠"
- 签到：今日页打卡收集 1 星尘；7 日连续→稀有星卡（正位金卡）；30 日→星光壁纸
- 星阶：累计星尘 0/7/30/100 → 微光/星光/星辉/星冠；星阶展示于名片+我的页

### P0-4 星象宜忌（今日星光卡升级）
- 今日星光卡 = 能量 4 格 + 星光色 + 星光数 + 星象宜忌（三行小字，标注真实天象出处——"准"字内核可视化）
- 文案红线（合规关键）：开放积极向（「宜·表达心意 / 忌·独自纠结」），禁"必/绝对/改运/化解/转运"；宜忌绑定真实天文事件（新月/满月/水逆/节气/行星相位），保证"有出处"

## 四、P1 中期规划（第 2 期，1 个月）

| 功能 | 星光化设计 | 服务 |
|---|---|---|
| 星光手账 | 情感日记升级：每日一个星点（情绪好=亮星/低落=暗星），月历着色成"我的星光夜空" | 情绪可视化+月度复盘 |
| 星辰相遇（合盘） | 双人星座/星盘匹配→"星辰相合度"+合盘牌阵→可分享 | 社交裂变（内置拉新） |
| 星象日历+节点活动 | 新月许愿/满月复盘/水逆期"自我关怀指南"（积极心理包装，非"化解"），节点触发晨讯召回 | 月度打开理由 |
| 睡前星语 | 晚 21:00 短句+月光卡（与晨讯共享 1 条/天额度） | 早晚陪伴 |

## 六、分期实施路线

1. 第 1 期（P0，2 周）：今日星光卡升级 → 星光晨讯 → 星尘签到+星阶 → 星光名片
2. 第 2 期（P1，1 月）：星光手账 → 星辰相遇 → 星象日历/节点活动 → 睡前星语
3. 第 3 期（P2，2-3 月）：星灵学堂 → 星象月报 → 星友圈

每期独立可上线可验证；第 1 期完成后即具备完整"星光宇宙"骨架。

## 七、合规红线（设计内嵌）

1. 去迷信化：结果页/海报带「仅供娱乐」免责；禁"必/绝对/改运/化解/转运"措辞；星光叙事天然柔和（星象宜忌<今日运势，且绑定真实天象）
2. 付费形态：会员制+深度报告（知识付费包装），不做按次付费占卜；星光晨讯/星尘免费
3. 推送纪律：每天 1 条封顶、可关闭；分享海报过内容安全检测
4. 数据安全：出生信息加密存储（沿用 api_security_redline）；订阅授权可撤销

## 八、风险与实施要点

- 订阅消息模板申请可能被拒（类目限制）→ 备选：模板用"服务通知"类目或引导关注公众号（P2 社区承接）
- 星光名片小程序码需落地页（tabbar 不可生成码）→ 第 1 期实施时新建 /pages/card-landing/
- 星阶/星尘数值可运营调整（A/B 测 7/30/100 门槛）
- 每日免费解读与现有分享奖励 free_deep_readings 共用字段，注意配额叠加规则
- 调研数据锚点：情感类留存 45% vs 娱乐 28%；签到 +63% 7 日活跃；推送打开率 3-5 倍；分享用户回访率更高
