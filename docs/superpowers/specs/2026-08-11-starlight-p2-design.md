## 一、星灵学堂（78 张牌学习 · 塔罗师养成）

### 1.1 用户流程（5 步）

1. **入口**：首页 foot-entry 区新增「星灵学堂」→ `pages/academy/academy`（学堂主页：路径四选 + 我的进度星图 + 今日学习卡）
2. **选路径**：四张路径卡——大阿卡纳之旅（22）/ 小阿卡纳四元素（56）/ 随机今日之牌（每日 1）/ 我的关联牌（按历史抽牌频次）。未选过默认引导选"大阿卡纳之旅"
3. **学一张牌**：`pages/academy/lesson?card_id=`——一屏一张学习卡（牌面大图 + 关键词 + 符号解读 + 典故 + 生活关联 + 元素归属），学完点「我已记住这颗星」
4. **陪学（可选）**：学习卡底部「问小星」→ 半屏对话（`pages/academy/chat`，AI 讲解牌意/典故/生活关联，非占卜）
5. **设计划（可选）**：学堂内「每日学习计划」——每日 N 张（1/3/5）+ 提醒开关 → 次日 7:37 晨讯/21:00 星语内容切换为"今日学牌"，学满当日额度即当日停发提醒

### 1.2 交互与视觉要点（E3 星光叙事）

- **学堂主页 = 星空书卷**：顶部"我的星图"——78 颗星点排成环（大阿卡纳 22 颗亮金 + 小阿卡纳 56 颗按四元素配色），已学点亮、未学呈淡星尘点（与手账夜空同语言）；进度文案"78 颗星里，你已经点亮了 N 颗"
- **四路径卡**：大阿卡纳=「愚者之旅」（0→21 的成长旅程叙事）、小阿卡纳=「四元素庭院」（权杖火/圣杯水/宝剑风/星币土，四色分区）、随机=「今日之牌」（与今日抽牌同牌，学"今天的指引"）、关联牌=「与你相遇的牌」（readings 历史 TOP）
- **学习卡版式**：牌面大图 + 左侧星光色描边（取牌元素色）；四区块渐进展开——关键词（3 个星光词）→ 符号解读（symbols 逐条）→ 典故（story）→ 生活关联（life_connection 一行）；底部「我已记住 ✦」按钮 + 「问小星」胶囊
- **学完动效**：星点从淡转亮（transition 星光色填充）+ toast"这颗星，为你点亮 ✦"
- **里程碑庆祝**：全通大阿卡纳/全通 78 张时全屏星光雨庆祝页 + 称号授予
- **陪学对话**：气泡式，小星头像（复用星灵·小星形象）+ 星光色气泡；回答 ≤200 字、底部常驻「仅供娱乐 · 星光映照」小字
- 空态：未开始学习时"78 颗星在书卷里等你——从愚者之行走起"

### 1.3 数据模型 + 接口草案

**决策：学习进度独立成表（不复用 diary/checkin）；学习计划 1 用户 1 条；陪学配额独立计数字段（与 free_chats_today 分离，避免与占卜追问互相挤占）。**

```sql
-- 新增表 1：学习进度（一牌一条；learned=已学，review_count=复习次数）
CREATE TABLE star_learning_progress (
    id           CHAR(36) PRIMARY KEY,
    user_id      CHAR(36) NOT NULL INDEX,     -- users.id
    card_id      INT NOT NULL,                -- tarot_cards.id
    learned_at   DATE NOT NULL,               -- 首次学完（北京时间）
    review_count INT NOT NULL DEFAULT 0,
    created_at DATETIME, updated_at DATETIME,
    UNIQUE KEY uq_user_card (user_id, card_id)
);

-- 新增表 2：学习计划（1 用户 1 条；cards_per_day=0 视为未开启）
CREATE TABLE star_learning_plans (
    user_id      CHAR(36) PRIMARY KEY,
    cards_per_day INT NOT NULL DEFAULT 0,     -- 0=关闭 | 1|3|5
    reminder_on  BOOL NOT NULL DEFAULT FALSE, -- 学习提醒开关（默认关）
    path         VARCHAR(16) NOT NULL DEFAULT 'major',  -- major|minor|random|related
    cursor_pos   INT NOT NULL DEFAULT 0,      -- 路径游标（major 0-21 / minor 0-55；random|related 按日派生忽略游标）
    created_at DATETIME, updated_at DATETIME
);

-- users 表加列（配学配额，与 diary_ai_count_today 共用 quota_reset_date 复位）
ALTER TABLE users ADD COLUMN academy_chat_count_today INT NOT NULL DEFAULT 0;
```

| 接口 | 方法 | 说明 |
|---|---|---|
| `/academy/overview` | GET | 学堂主页：总进度 `{total, learned, percent}` + 四路径各自进度 + 已获称号 + 今日学习卡（random 路径按日确定性取） |

| `/academy/plan` | GET/POST | 学习计划读写 `{cards_per_day, reminder_on, path}`；开启提醒时校验已有订阅额度（无额度给引导授权提示，不硬拦） |

**学习提醒推送实现（关键决策：主题切换，非新槽位）**：
- `daily_push` 槽位内容优先级改为：**节点日主题 > 学习提醒主题 > 常规晨讯/星语**
- 触发条件：plan.reminder_on=true + 有 quota + 今日未学满 cards_per_day + 非节点日 → thing1=`今日学牌：{牌名}`（≤20 字）、thing2=`关键词·{k1}{k2}`、thing3 用 date3=日期、thing4=`点击点亮这颗星 ✦`、page=`pages/academy/lesson?card_id=`
- 学满当日 N 张后当日不再发（省额度，用户完成感即时）；节点日（新月/满月/水逆首日）优先召回不因学习计划丢失
- 1 条/天纪律不破；学习提醒**默认关闭**，开启需在计划页明确告知"学习提醒日，当天星光晨讯/星语将换成今日学牌"

### 1.7 风险

- **提醒挤占常规内容**：学习提醒替换当日晨讯/星语 → 默认关闭 + 设置页明示 + 学满即停发；用户可随时关（列入待确认问题）
- **AI 陪学成本**：3 次/天×~500 tokens 免费层可控；无 key/失败降级为"小星在休息，先看看学习卡吧"（不空屏）；缓存教学讲解（同卡同人二次提问直接回短版）
- **星尘通胀**：全通 +19 封顶（低于星阶 30 门槛的一半），且需要真实学习 78 张，激励大于刷量；里程碑幂等防重刷
- **学习完成定义**："我已记住"是自报 → 用 review_count 与路径推进制造二次回访，不做强制测验（防挫败）

## 二、星象月报（会员专属周/月报告 · 复购引擎）

### 2.1 用户流程（4 步）

1. **入口**：我的页"星象月报"卡（周报/月报两个 Tab）+ 会员页权益位 → `pages/report/star-report?tab=week|month`
2. **看报告**：周报（每周一后可看上周）/ 月报（每月 1 日后可看上月）——顶部报告期切换器 + 期数选择（最近 4 期）
3. **解锁（非会员）**：非会员打开 → 免费预览（周报：星运曲线+1 段寄语；月报：封面+目录）→ 底部"解锁全文"→ 微信支付（周报 4.9 / 月报 19.9）或"开通会员免费看"
4. **分享**：报告页"生成海报"→ 周报海报（升级版）/ 月报封面海报（星阶徽章+3 核心数字+小程序码）→ 保存/转发拉新

### 2.2 交互与视觉要点

- **报告页 = 星光卷轴**：自上而下分区——期头（报告期 + 星阶徽章）→ 星运曲线 → 统计卡 → AI 段落 → 下期预告 → 分享栏；每区星空色描边卡片，与手账/名片同系
- **周报结构（上周一~周日）**：
  1. 星运曲线：7 天能量总分折线 + 每日星光色点（horoscope_history）
  2. 星尘统计：本周星尘增减（签到/手账连续/节点打卡计数）
  3. 牌运回顾：抽牌 N 次 + 最常出现的牌（卡图+关键词）+ 牌列表横滑
  4. AI 周寄语 ≤60 字（升级现有 /report/weekly 语义）
  5. 本周星光色带（7 色点串）
- **月报结构（上月）**：
  1. 月度星象复盘：上月天象事件表（新月/满月/水逆/节气，复用 ASTRAL_EVENTS_2026）+ 每事件一句宜忌
  2. 星光手账汇总：点亮 N 天 / 亮暗比例 / 情绪趋势——直接引用 `star_monthly_reviews` 缓存（不重复调 AI）
  3. 牌运回顾：月度抽牌统计 + TOP3 牌
  4. 星尘与星阶：本月星尘增量 + 星阶变迁（"微光 → 星光"）
  5. 下月展望：下月天象预告（新月/满月/水逆首日日期）+ 温柔行动建议（"下月新月之夜，给自己留一页空白"——**活动预告，非运势预测**）
  6. AI 月度总评（`_AI_RED_LINE`）
- **空态**：上月无数据 → 报告照常生成（统计 0 + 温柔引导"夜空等着被你点亮"），不挫败
- **非会员预览态**：可下滑预览，未解锁区块毛玻璃模糊 + 锁形标记；解锁按钮吸底

### 2.3 数据模型 + 接口草案

**决策：仿 star_monthly_reviews 缓存模式（按人按周期一份）；懒生成（打开才生成，不做全量批处理 AI）；统计段纯 SQL 确定性聚合，AI 只写文案段（成本可控）；重新生成覆盖缓存（会员限流）。**

```sql
-- 新增表：报告缓存（周/月共用一张表）
CREATE TABLE star_reports (
    id           CHAR(36) PRIMARY KEY,
    user_id      CHAR(36) NOT NULL INDEX,
    report_type  VARCHAR(8) NOT NULL,          -- week | month
    period_key   VARCHAR(12) NOT NULL,         -- '2026-W33' | '2026-08'
    data         TEXT NOT NULL,                -- 完整报告 JSON（统计+AI 段落+海报字段）
    source       VARCHAR(8) NOT NULL,          -- ai | fallback
    generated_at DATETIME,
    updated_at   DATETIME,
    UNIQUE KEY uq_user_type_period (user_id, report_type, period_key)
);
```

**权益与定价（PRODUCTS 新增两 SKU）**：

| 报告 | 会员 | 非会员 |
|---|---|---|
| 周报 | 免费全文 | 预览（曲线+1 段）+ 4.9 解锁全文 |

## 三、星友圈（今日星光共鸣 · 结构化轻社区）

### 3.1 用户流程（5 步）

1. **入口**：首页 foot-entry 区「今日共鸣」→ `pages/resonance/resonance`（共鸣墙）；首次进入弹「星光公约」说明

### 3.2 交互与视觉要点

- **墙 = 夜空上的星星卡片**：每张共鸣卡即一颗星——脱敏星名（系统生成"星星·X"）+ 星座徽章 + 星光数 + 今日牌小图 + 星阶徽章 + 右侧 ✦ 共鸣按钮（计数）

- **公约弹窗**（首次进入）：三行说明——"这里展示的是：你的星名、星座、星光数、今日牌与星阶（均为系统生成）；这里不展示：你的微信昵称头像、出生信息、日记与解读内容；随时可在我的页关闭展示"
- 空态：今日无人同组时"今晚的夜空有些安静——你的星先亮着 ✦"

### 3.3 数据模型 + 接口草案

**决策：不建每日快照表——墙为实时聚合（当前用户量下 SQL 查询毫秒级；数据量为 N 百时再评估快照优化，预留演进方向即可）；共鸣记录唯一约束防刷；展示内容 100% 脱敏（星名为系统生成，非微信昵称）。**

```sql
-- 新增表：共鸣记录（1 人同日对 1 人仅 1 次）
CREATE TABLE star_resonances (
    id            CHAR(36) PRIMARY KEY,
    from_user_id  CHAR(36) NOT NULL INDEX,     -- 共鸣者 users.id
    to_user_id    CHAR(36) NOT NULL INDEX,     -- 被共鸣者 users.id
    resonate_date DATE NOT NULL,               -- 共鸣日期（北京时间）
    created_at    DATETIME,
    UNIQUE KEY uq_from_to_date (from_user_id, to_user_id, resonate_date)
);

-- users 表加两列
ALTER TABLE users ADD COLUMN resonance_visible BOOL NOT NULL DEFAULT TRUE;
ALTER TABLE users ADD COLUMN star_alias VARCHAR(16) NULL;   -- 脱敏星名（首次进墙时生成：'星星·晚风' 式，确定性词库 40 词轮换）
```

**墙聚合口径**：
- 今日活跃 = 今日有 horoscope_history 记录（即今天看过今日星光）或今日有日记/签到/共鸣 的用户，且 resonance_visible=true
- 展示字段：star_alias、zodiac、star_number（build_today_guidance 确定性取）、今日牌 card_id+name、star_tier、今日收到共鸣数
- 分组：同 zodiac / 同 star_number / 同今日牌；组内共鸣数降序 + 日种子轮换头部防固化
- 不含：昵称、头像、openid、出生信息、解读内容、日记内容

| 接口 | 方法 | 说明 |
|---|---|---|
| `/resonance/wall` | GET | 共鸣墙：`{active_count, groups: [{type, label, members: [{alias, zodiac, star_number, card, tier, resonate_count, resonated_by_me}]}], my_card: {…, received_today}}`（全部脱敏字段；公开页免登录可看但限流） |
| `/resonance/give` | POST | 共鸣 `{to_user_id}`：幂等（同日同人唯一约束）+ 每日上限 10 次（超出返回 friendly 提示"今天已经送出 10 颗星，明天再来"） |

- 墙接口独立限流（同 meet 公开接口模式：30 次/分/IP）；to_user_id 为内部 UUID，仅共鸣/海报用途，返回无任何可联系字段

## 四、三功能关联设计：闭环链条

**1. 星灵学堂 → 月报素材（个人化加深）**
学习进度进入月报牌运回顾段："这个月你点亮了 N 颗星，其中 {星币七、圣杯三…} 成了你常复习的牌"——月报从"数据报告"变为"成长记录"，复习行为也被月报反哺（看到"常复习的牌"→ 想再去复习）。

**2. 月报 → 分享拉新（复购×裂变双引擎）**
月报海报带小程序码 → card-landing 落地 → 新用户注册 → /share/invite 双向 +1 免费解读。非会员看预览→付费/开会员（复购）；分享海报→拉新（裂变）。月报是 P2 商业化主线。

**3. 星友圈 → 共鸣海报 → 名片体系闭环**
共鸣海报 = 双星版式身份卡（复用 E3 名片样式与星阶徽章）→ 带码分享 → 拉新 → 新用户进共鸣墙 → 产生更多共鸣。共鸣墙的数据（星光数/牌/星阶）全部来自名片体系同源（build_today_guidance + tier）——"一张名片，两个入口"。

**4. 星尘经济第四来源**
学堂里程碑（+19 封顶）加入星尘来源（签到/手账/节点/学堂）→ 星阶（微光→星光→星辉→星冠）推进加速 → 名片/海报星阶徽章更亮 → 分享意愿更强。共鸣**不**产星尘（防刷），星尘只奖励"自我成长"类行为。

**5. 推送体系扩展（仍 1 条/天）**
学习提醒 = 晨/晚槽位内容主题（节点 > 学习 > 常规 三态优先级）——不新增条数、不破坏防疲劳纪律；月报生成/共鸣红点**不走订阅消息**（站内红点），推送纪律零变化。

**6. 情感主线延续**
手账（情绪）→ 月报（回顾）→ 共鸣（被看见）→ 学堂（成长）：四条情感/成长线在月报一处交汇，月报成为"我的星光宇宙月度快照"。

**7. 入口统一**
