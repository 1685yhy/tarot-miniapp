# 产品定位强化计划

> 把星光映照打造成"AI塔罗陪伴空间"品类第一

## 四线并行

### Task 1: 教学深度无处不在
- 每日一牌: 翻牌后追加"今日牌面知识"(1个符号+典故)
- 百科首页: 顶部加"今日塔罗故事"随机卡片深度内容
- 解读结果: 深度解析区改为默认展开(非折叠)

### Task 2: 情感日记升级
- 写日记页: 加AI提示"这张牌让你想到什么？"
- 日记列表: 每条显示关联牌面缩略图
- AI周回顾: 加情感曲线可视化(emoji趋势线)

### Task 3: AI角色情感连接
- 占卜结果页: 显示"本次由 {persona.name} 为你解读" + 角色小传
- 个人页: "你的专属塔罗师"区块，展示最常用角色+解读次数
- 角色切换: 首次切换时展示角色介绍卡片

### Task 4: 信任信号强化
- 所有AI解读底部: "✨ AI生成 · 塔罗是镜子而非预言 · 仅供参考"
- 首页: "每日一牌，遇见自己" → 强化为品牌标语
- 我的页: 底部"关于星光映照"入口
