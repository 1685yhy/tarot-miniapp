## 二、用户可见变化（存量行为变更）

1. **21:00「今晚之牌」→ 睡前星语（额度制）**：未重新授权订阅的用户晚间不再收到推送。微信一次性订阅消息为固有机制，无法自动续订——老用户需在设置页重新授权一次才能恢复晚间推送。
2. **晨讯 / 星语二选一**：默认晨讯（7:37）；切换偏好后次日生效；同日最多收到 1 条（双槽位共享上限）。
3. **手账与情感日记合并**：原日记页跳转手账，仅视图升级，**数据不迁移**（历史日记仍在原表，手账为新增视图）。
4. **水逆打卡按「天」语义**：水逆区间内每天可打卡一次（非整个区间一次），奖励幂等不重复发放；许愿窗口期打卡会被拒绝（产品语义确认）。
5. **月光卡 / 晚安卡**：可保存、可分享海报（带名片码，跳手账沉淀链路）。
