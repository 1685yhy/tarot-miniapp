# 塔罗占卜微信小程序 - 产品设计文档

## 项目概述

- **产品名称**：待定（塔罗占卜类微信小程序）
- **产品定位**：AI自助式塔罗占卜工具，免费引流+付费深度解读
- **目标用户**：对塔罗占卜感兴趣的C端用户
- **商业模式**：每日免费1次 → 单次深度解读(9.9-19.9元) → 永久会员(98-198元) → 年度运势报告(29.9-49.9元)

## 技术架构

```
用户 → 微信小程序 → HTTPS → 云服务器(Python/FastAPI)
                                  ├── Claude API（塔罗解读引擎）
                                  ├── MySQL（用户/订单/牌义数据）
                                  └── Redis（缓存/会话）
```

- **前端**：微信小程序原生框架
- **后端**：Python (FastAPI)，部署阿里云/腾讯云
- **AI引擎**：Claude API
- **数据库**：MySQL + Redis
- **支付**：微信支付

## 功能清单

### 免费功能
- 🔮 每日运势：每天免费抽1张牌 + AI运势解读
- 📖 塔罗百科：78张牌完整图鉴（描述、正位、逆位、关键词）
- 🎴 单牌速查：分类浏览、搜索

### 付费功能
- 💰 深度牌阵占卜：10+种专业牌阵（爱情/事业/财运/选择/人生十字等）
- 🤖 AI对话解读：抽牌后可追问，深入探讨
- 👑 永久会员：无限次数所有功能
- 📊 年度运势报告：12个月详解，可分享

### 增长功能
- 🔗 分享裂变：分享结果双方得免费次数
- 🏷️ 运势卡片：精美图片卡片可分享朋友圈
- 📝 塔罗日记：每日心情+抽牌反思，形成个人成长轨迹

## 数据内容需求

### 78张塔罗牌结构化数据
- 22张大阿尔卡纳（Major Arcana）
- 56张小阿尔卡纳（Minor Arcana：权杖、圣杯、宝剑、星币各14张）
- 每张牌含：名称(中/英)、牌面描述、正位含义、逆位含义、关键词、爱情/事业/财运各维度解读

### 牌阵规则
- 单牌牌阵、三牌牌阵、凯尔特十字、恋人三角、二择一、事业牌阵等

### AI解读案例
- 真实场景结合案例（训练AI用）

### 塔罗日记Prompt模板
- 每日反思引导语
